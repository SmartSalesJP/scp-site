# SCP — Smart Creative Promotion

若手アーティスト・個人クリエイター向け SNS 発信プロモーション支援「SCP」のランディングページ。

- 公開URL: https://scp-tokyo.site （GitHub Pages）
- 自己完結の静的サイト（`index.html` ＋ `vendor/three.min.js`）。外部CDN非依存。
- お問い合わせ: info@scp-tokyo.site

## 公開設定
- Settings → Pages → Source: Deploy from a branch → `main` / `(root)`
- 独自ドメインは `CNAME`（scp-tokyo.site）で指定。DNS の A レコードを GitHub Pages に向ける。
